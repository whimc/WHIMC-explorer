How to generate a file to upload

For manual exports, run the exporter on the Windows Minecraft server, or a Windows computer with access to its records. With website exports configured, use Request server exports above instead.

  1. Prepare once. Download and extract the source ZIP from the release matching your installed portal. Open PowerShell in that extracted project folder. Use Python 3.12 and install the exporter dependencies in a virtual environment: 
    py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r web/requirements.txt -r tools/requirements.txt
    Copy tools/export-config.example.json to your private local-config.json. Set the server ID and tracker database details with your server administrator; use a database account with SELECT-only access. Use your reviewed catalog.json containing the correct worlds, map bounds and POIs. The packaged example catalog is synthetic.
  2. Choose the learner and study window. After play has finished and records have been saved, use the learner's Minecraft UUID and the study location's timezone. For example, America/New_York means Eastern and America/Denver means Mountain with daylight saving. The server and evaluator computer can remain in other timezones.
  3. Export one learner. Replace every example value below, including UUID, dates, names and journal path. Run this command on one line in PowerShell: 
    .\.venv\Scripts\python.exe tools/export_session.py --config local-config.json --catalog catalog.json --player 00000000-0000-4000-8000-000000000001 --label 'Learner 01' --study 'Fall habitat study' --location 'Study school' --session-name 'Week 1 morning' --timezone America/New_York --start 2026-10-09T09:00:00 --end 2026-10-09T12:00:00 --journal 'D:/Minecraft/plugins/WHIMC-Explorer/journal' --output learner-01-morning.json
    Enter the database password at the local prompt. The output is saved in the current folder; use a new filename for each export. The start is included and the end excluded. For afternoon, use 13:00:00 through 16:00:00. Daylight-saving offsets are calculated from the selected timezone and date.
  4. Upload the resulting JSON below. Choose learner-01-morning.json, then select Import session. Repeat the export and upload for each learner. Use the same study and location labels to find them together in Compare paths.

Upload only the generated session bundle. Keep database passwords, local-config.json, raw databases and journal folders on the server or your private computer. If you only evaluate sessions, ask your server administrator for the exported JSON.
