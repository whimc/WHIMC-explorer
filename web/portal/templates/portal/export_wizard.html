2. Study time window

Use the study's clock times. A preset uses the start date for one morning or afternoon. A custom range includes all hours between its endpoints, not repeated daily study hours. Maximum seven elapsed days. The local exporter validates daylight-saving changes and rejects ambiguous or nonexistent times.

3. Local files

Relative paths are resolved from the extracted Explorer source folder where you run the script. These are Windows paths, not cPanel paths.

Include the saved journal for NPC interactions and recorded teleport breaks. Without it, those sources are unavailable. The script does not assert complete capture.

For selected learners, each filename gains the friendly name and UUID automatically. Use an existing folder and a new base filename. Existing files are never overwritten. Never enter passwords here.

4. Run locally, then upload

Open PowerShell in your extracted Explorer source folder with its prepared .venv. Copy and paste the complete script, or save the download there and run .\export-session.ps1. If your computer blocks script files, paste the reviewed script into PowerShell instead of changing its execution policy.

Use the updated source package containing tools/export_batch.py. The batch prompts once for the database password, then exports one JSON per selected learner. Failed learners are reported separately; successful exports remain available. Choose all resulting .json files in the upload form below. Do not upload the .ps1 script.
